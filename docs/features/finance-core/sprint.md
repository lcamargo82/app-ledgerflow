# Sprint: Nucleo Financeiro

## Objetivo

Entregar as primeiras funcionalidades que tornam o app util: contas, categorias, transacoes e transferencia.

## Tarefas

- [ ] Definir contratos de API para contas.
- [ ] Definir contratos de API para categorias.
- [ ] Definir contratos de API para transacoes.
- [ ] Definir contratos de API para transferencias.
- [ ] Criar modelos Flutter para conta, categoria, transacao e transferencia.
- [ ] Criar repositories de contas, categorias e transacoes.
- [ ] Implementar tela "Minhas Contas".
- [ ] Implementar tela "Gerenciar Categorias".
- [ ] Implementar formulario de nova transacao.
- [ ] Implementar formulario de transferencia.
- [ ] Implementar tela de detalhes da transacao.
- [ ] Atualizar dashboard apos mutacoes.
- [ ] Criar validacoes de formulario.
- [ ] Criar testes de modelos e repositories.

## Definicao De Pronto

- Fluxo de criar receita/despesa funciona.
- Lista de contas mostra saldos.
- Categorias podem ser gerenciadas.
- Transferencia entre contas atualiza os dados apresentados.
- UI segue o design system escuro.
