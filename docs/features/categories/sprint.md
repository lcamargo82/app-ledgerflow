# Sprint: Categorias

## Objetivo

Implementar gerenciamento de categorias por workspace.

## Tarefas

- [ ] Criar modelo `Category`.
- [ ] Criar enum Flutter para `CategoryType`.
- [ ] Criar `CategoriesApi`.
- [ ] Criar `CategoriesRepository`.
- [ ] Criar providers por tipo.
- [ ] Implementar tela com tabs Receita/Despesa.
- [ ] Implementar busca local ou query `search`.
- [ ] Implementar formulario de criar/editar.
- [ ] Criar mapper de icones por string.
- [ ] Criar swatches de cor.
- [ ] Ocultar `ADJUSTMENT` em seletores comuns.
- [ ] Invalidar transacoes/dashboard quando categoria mudar.
- [ ] Testar filtros e parser.

## Definicao De Pronto

- Categorias reais aparecem por workspace.
- Formulario valida nome, tipo, cor e icone.
- Seletores de transacao usam categorias compativeis.
